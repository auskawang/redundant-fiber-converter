# PCB source assets

| Path | Contents |
| --- | --- |
| `exports/` | Schematic, PCB layer prints, and original top/bottom 3D PDFs |
| `images/` | Original layout/rule/xSignal/JLCPCB captures and derived 3D previews |
| [Combined PDF](PHOTON_PCB_Design_Evidence.pdf) | 69-page bookmarked tour |

Original capture resolution and PDF page sizes are retained. Fabrication drawings omitted from the showcase remain in the original project workspace. This archive documents displayed design state, not manufacturing sign-off or measured performance.
